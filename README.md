# Weather

## Описание

Приложение для просмотра погоды на JavaScript

## Технологии

- HTML
- SCSS
- JavaScript
- Vite
- ESLint
- Prettier
- API

## Функциональность

- Поиск города для просмотра погоды
- Добавление городов в избранное
- Просмотр погоды на текущий день
- Просмотр дополнительных данных о погоде
- Просмотр прогноза погоды на 7 дней

## Как запустить локально

`git clone git@github.com:Kustiche/weather-vanilla-js.git`
`cd weather-vanilla-js`
`npm install`
`npm run dev`
